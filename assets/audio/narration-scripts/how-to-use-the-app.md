# How to Use the App - Narration Script

## Navigation

The main navigation allows you to move between five sections:

**Home**: Returns you to the welcome screen and overview

**EBP Library**: Browse all 29 evidence-based practices organised by category

**Case Studies**: Explore real-world examples from Irish schools

**Rights and Ethics**: Access legal frameworks and ethical guidance

**Tools**: Use practical planning and assessment tools

## Using the EBP Library

In the EBP Library, you'll find 29 evidence-based practices organised into categories:
- Environmental Support
- Social-Emotional
- Behavioural Support
- Instructional Strategy
- Communication Support

Select any practice to view:
- What it is
- Why it matters
- How to implement
- Practical Irish examples
- Ethical considerations
- Related practices

Use the bookmark icon to save practices you want to return to.

## Case Studies

Case studies show how evidence-based practices are implemented in real Irish schools.

Each case study includes:
- Student background
- Challenges and goals
- Which EBPs were used and why
- Implementation details
- Outcomes and reflections

Filter case studies by age, setting, or challenge type to find relevant examples.

## Planning Tools

The Tools section includes:
- Lesson Script Generator: Create classroom-ready lesson plans
- Transition Support Builder: Plan structured transitions
- Parent Assessment: Gather family insights
- School Daily Planner: Build evidence-informed daily schedules
- Student Voice Tool: Record student perspectives
- Social Narrative Creator: Generate personalised social stories
- VR Planning Tools: Design virtual reality learning experiences

All tools allow you to save your work and export or email completed plans.

## Audio Narration

To use audio narration:
1. Open narration settings from the header
2. Enable audio narration
3. Adjust voice, speed, pitch, and volume preferences
4. Look for play buttons next to content sections
5. Click play to hear content read aloud
6. Use pause and stop controls as needed

Your narration preferences are saved automatically.

## Tips for Success

- Use search to quickly find specific topics
- Bookmark frequently-used practices and tools
- Enable audio narration if you prefer listening to reading
- All your saved plans and preferences stay on your device
- No internet connection needed once content is loaded
