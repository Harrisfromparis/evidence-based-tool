# Visual Supports

## What it is

Using visual materials (pictures, symbols, written words, objects, videos) to support understanding, communication, and independence. Visual supports make abstract concepts concrete and provide information that remains visible over time.

## Why it matters

Many autistic individuals are strong visual learners. Spoken language is transient and must be processed quickly; visual supports remain available for review and reduce reliance on auditory processing and working memory.

## How to implement

1. **Identify need**: Where does the student struggle with understanding, remembering, or organising?
2. **Choose format**: Pictures, photographs, symbols, written words, objects, or video
3. **Make it visible and accessible**: Place supports where student can easily see and use them
4. **Teach how to use**: Explicitly show student how to reference the visual support
5. **Fade only if appropriate**: Some supports should remain permanently; others can be reduced as skills develop

### Types of visual supports

- **Schedules**: Show sequence of activities (daily schedule, task sequence, routine steps)
- **Timers**: Visual representation of time passing or remaining
- **Choice boards**: Display options for activities, materials, or preferences
- **Social supports**: Visual reminders of social expectations or scripts
- **Organisational supports**: Checklists, calendars, assignment organisers
- **Labelling**: Clear labels on materials, spaces, and resources
- **Rules and expectations**: Visual representation of classroom expectations

### Practical examples

- Photo schedule showing daily class routine
- Visual timer showing time remaining for activity
- Choice board with pictures of break activities
- First-Then board: "First maths worksheet, Then computer time"
- Visual rules posted in classroom
- Labelled bins for materials and belongings
- Social script card for asking to join group
- Transition countdown strip (5 → 4 → 3 → 2 → 1 → Transition)

## Good to know

- **Not infantilising**: Visual supports benefit all ages when format is age-appropriate
- **Individual preferences**: Some students prefer photos, others prefer symbols or words
- **Keep them available**: Don't remove supports too quickly; independence may require ongoing visual support
- **Consistency across settings**: Visual supports work best when used across all environments

## Evidence base

Visual supports have extensive research support as one of the most effective practices for autistic learners. Studies show improvements in communication, organisation, task completion, behaviour, and independence.
