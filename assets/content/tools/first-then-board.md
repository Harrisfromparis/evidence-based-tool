# First-Then Board

## Purpose

A First-Then board shows a simple two-step sequence: complete this task first, then access preferred activity. This tool reduces resistance by providing clear information about what comes next and motivation for completing non-preferred tasks.

## Who it is for

- Students who struggle with transitions between activities
- Learners who need concrete information about upcoming events
- Anyone who resists non-preferred tasks
- Students learning to delay gratification
- Learners working on following multi-step directions

## How to use

1. **Create board**: Use simple board with "First" and "Then" clearly labelled
2. **Select first activity**: Place picture/symbol/word of required task under "First"
3. **Select then activity**: Place picture of motivating activity under "Then"
4. **Present to student**: Show board and say "First [task], then [preferred activity]"
5. **Support completion**: Help student complete first task
6. **Honour the "then"**: Immediately provide promised activity
7. **Repeat throughout day**: Use for multiple transitions

### Tips for effectiveness

- Choose genuinely motivating "then" activities
- Start with very brief "first" tasks to build pattern
- Always honour the "then" - consistency is critical
- Use visual format student understands (photos, symbols, or words)
- Gradually increase duration or difficulty of "first" task
- Fade verbal prompts once student understands the system

### Example sequences

- First: Maths worksheet → Then: Computer time
- First: Wash hands → Then: Snack
- First: Tidy toys → Then: Go outside
- First: Write three sentences → Then: Drawing
- First: Group work → Then: Independent reading

## Notes

- This is not bribery - it's providing clear information about sequence
- The "then" must immediately follow the "first" to maintain effectiveness
- Can expand to "First-Next-Then" for three-step sequences
- Portable formats (laminated cards, photos on keyring) allow use across settings
- Some students use First-Then boards long-term as effective support
- Respect that knowing what's next reduces anxiety, even if it doesn't eliminate resistance
