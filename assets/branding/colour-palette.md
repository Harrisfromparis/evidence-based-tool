# Colour Palette

## Official Brand Colours

### Black
**Hex:** #000000  
**Usage:** Primary text, headings, key UI elements  
**Purpose:** Conveys authority, professionalism, and clarity appropriate for educational content

### Green
**Hex:** #2ECC71  
**Usage:** Interactive elements, success states, positive indicators  
**Purpose:** Represents growth, support, and affirmative actions

### Orange
**Hex:** #F39C12  
**Usage:** Accent highlights, calls-to-action, attention elements  
**Purpose:** Creates warmth, energy, and draws attention to important information

### Soft Green
**Hex:** #A8E6CF  
**Usage:** Backgrounds, hover states, subtle section dividers  
**Purpose:** Provides calm, gentle visual support without distraction

### Soft Orange
**Hex:** #FFD3B6  
**Usage:** Secondary backgrounds, gentle highlights, warm accents  
**Purpose:** Adds warmth and approachability to the interface

### Neutral Grey
**Hex:** #F2F2F2  
**Usage:** Page backgrounds, card backgrounds, neutral spaces  
**Purpose:** Creates clean, professional canvas for content

## Application Guidelines

- Use black for all primary text to ensure maximum readability
- Apply green to interactive elements consistently across the application
- Reserve orange for truly important calls-to-action
- Use soft tones for backgrounds and supporting elements
- Maintain high contrast ratios for accessibility compliance
- Never use colour as the only means of conveying information
