# Typography Standards

## Font Family

### Primary Font: Inter
**Usage:** Body text, UI elements, general content  
**Rationale:** Exceptional readability, dyslexia-friendly letterforms, neutral professionalism

**Weights:**
- Regular (400): Body text, paragraphs, general content
- Medium (500): UI elements, labels, navigation
- Semi-Bold (600): Subheadings, emphasis, card titles
- Bold (700): Headings, primary emphasis

### Display Font: Merriweather (for headings)
**Usage:** Page titles, section headers, major headings  
**Rationale:** Brings editorial authority and traditional publishing credibility

**Weights:**
- Bold (700): All heading levels

## Hierarchy

### Headings

**H1 - Page Titles**
- Font: Merriweather Bold
- Size: 32px
- Line height: 1.2
- Letter spacing: -0.02em
- Weight: 700

**H2 - Section Headings**
- Font: Merriweather Bold
- Size: 24px
- Line height: 1.3
- Letter spacing: -0.01em
- Weight: 700

**H3 - Subsection Headings**
- Font: Inter Semi-Bold
- Size: 18px
- Line height: 1.4
- Letter spacing: 0
- Weight: 600

### Body Text

**Primary Body**
- Font: Inter Regular
- Size: 16px
- Line height: 1.6
- Letter spacing: 0.01em
- Weight: 400

**Secondary Body / Captions**
- Font: Inter Regular
- Size: 14px
- Line height: 1.5
- Letter spacing: 0.01em
- Weight: 400

### UI Elements

**Buttons**
- Font: Inter Medium
- Size: 16px
- Weight: 500

**Labels**
- Font: Inter Medium
- Size: 14px
- Weight: 500

**Navigation**
- Font: Inter Medium
- Size: 16px
- Weight: 500

## Accessibility Guidelines

- Maintain minimum 16px for body text
- Use line height of at least 1.5 for body text
- Ensure sufficient letter spacing for readability
- Never use text smaller than 14px
- Maintain strong contrast ratios with background colours
- Avoid using italic or underline except for emphasis or links
