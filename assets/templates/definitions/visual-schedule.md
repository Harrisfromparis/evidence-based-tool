# Visual Schedule Template

## Purpose
Create a visual representation of activities in sequence, reducing anxiety and supporting independence.

## Sections

### Header
- Student name
- Date
- Schedule type (full day / single period / specific routine)
- Format (photos / symbols / words)

### Time Column (optional)
- Start time for each activity
- Can be clock times or sequential order (1, 2, 3...)

### Activity Column
- Visual representation (photo, symbol, or word)
- Clear activity name below visual
- Space to mark completion (checkbox or "finished" indicator)

### Notes Column (optional)
- Location
- Materials needed
- Key people involved
- Accommodations for this activity

### Footer
- "If schedule changes, I will be told"
- Visual indicator for "finished" and "next"
- Space for special notes or changes

## Layout Rules

- Left-to-right or top-to-bottom sequence (consistent direction)
- Clear visual separation between activities
- Adequate size for visual elements (at least 3cm x 3cm for photos/symbols)
- Easy-to-mark completion indicators
- Portable size option for transitions
- Laminated for durability and reusability

## Visual Format Options

**Object schedule**: Actual objects representing activities (for pre-symbolic learners)

**Photograph schedule**: Real photos of activities, locations, materials

**Symbol schedule**: Icons or line drawings (e.g., Boardmaker symbols)

**Written schedule**: Text-based for readers

**Combination schedule**: Mix formats as needed

## Accessibility Notes

- High contrast between visual and background
- Clear, simple images without distracting details
- Consistent format across days
- Velcro or magnetic backing for removable pieces
- Size appropriate for student's visual and motor abilities
- Consider colour-coding by activity type (optional)

## Customisation

- Include student's photo next to "My Schedule" heading (ownership)
- Add motivating activities to encourage schedule-checking
- Include "surprise" or "choice" cards for flexible activities
- Create mini portable version for transitions between settings
- Consider "first-then-next" format for simpler three-step sequences
