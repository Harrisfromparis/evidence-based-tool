# Goal-Setting Sheet Template

## Purpose
Create specific, measurable, meaningful goals with clear action plans for achievement.

## Sections

### Goal Overview
- Student name
- Date created
- Goal area (communication / social / academic / daily living / emotional regulation / other)
- Person(s) responsible for goal
- Review date

### Current Situation
**Where are we now?**
- Brief description of student's current level in this area
- Specific observations
- Assessment data (if applicable)

### Goal Statement
**What are we working toward?**
- Specific, observable, measurable goal
- Timeline for achievement
- Success criteria (how will we know it's achieved?)

**Example**: "By [date], [student] will [specific behaviour/skill] in [context] with [level of support/accuracy] as measured by [assessment method]."

### Why This Goal Matters
- How will achieving this improve the student's life?
- Student's perspective (if available)
- Family priorities
- School priorities

## Layout Rules
- Clear section headers
- Adequate space for handwritten or typed notes
- Table format for multi-step actions
- Checkboxes for completion tracking
- Professional but accessible language
- Space for collaborative input

## Accessibility Notes
- Large, readable font
- High contrast
- Structured format for easy completion
- Option for visual supports alongside text
- Can be completed digitally or on paper
- Collaborative completion encouraged (student, family, school team)

## Ethical Considerations
- Goals must genuinely benefit the student
- Avoid goals aimed at suppressing harmless autistic traits
- Centre student wellbeing and autonomy
- Include student voice whenever possible
- Respect neurodivergent ways of being
- Focus on skill-building, not compliance
